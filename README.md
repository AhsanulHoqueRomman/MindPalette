# MindPalette 📝

A modern blogging platform built with Django, featuring user authentication, profile management, comments, likes, post views, contact system, and an admin dashboard.

## 🌐 Live Demo

**Website:** https://ahsanulhoqueromman.pythonanywhere.com

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/AhsanulHoqueRomman/MindPalette.git
cd MindPalette
```

### Create Virtual Environment

```bash
python -m venv env
```

### Activate Virtual Environment

Windows:

```bash
env\Scripts\activate
```

Linux/Mac:

```bash
source env/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Apply Migrations

```bash
python manage.py migrate
```

### Create Superuser

```bash
python manage.py createsuperuser
```

### Run Development Server

```bash
python manage.py runserver
```

Visit:

```text
http://127.0.0.1:8000/
```
